## Null handling

- Raw: 빈 문자열만 NULL로 적재(문자 'NA'는 값으로 보존).
- Staging: `DAYS_EMPLOYED=365243` → `days_employed_clean` NULL + `days_employed_anom=1`; previous `DAYS_*=365243` → `*_clean` NULL; `CODE_GENDER='XNA'`, `NAME_FAMILY_STATUS='Unknown'` → NULL.
- Model: LightGBM은 NaN을 기본 처리, Logistic Regression은 Train-fit median 대치 + missing indicator; 범주형은 'MISSING' 상수(LR) 또는 OrdinalEncoder 결측 코드(LightGBM).
