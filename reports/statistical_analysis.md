# 통계 분석 보고서 — TARGET 연관성 검정

> **⚠️ 합성(synthetic) 테스트 데이터 기반 결과 — 실제 Home Credit 분석 결과 아님**
>
> `raw.columns_description`의 설명이 `[synthetic]`으로 시작하여 합성 데이터로 자동 판별되었다. 아래 수치는 파이프라인 검증용이며 해석에 사용하지 않는다.

> **대표본 경고**: 분석 표본은 train 고객 30,000명이다. 실데이터(약 30만 행) 규모에서는 실무적으로 의미 없는 아주 작은 차이도 p-value가 매우 작아진다. 따라서 **결론은 효과크기(rank-biserial r, Cramér's V, Cohen's d)와 구간별 관측 상환곤란율 차이로 판단**하며, p-value는 보조 정보로만 사용한다. 이번 실행에서 BH 보정 후 유의한 33개 검정 중 14개는 효과크기가 '무시할 수준'이다.

## 방법

- **수치형**: Mann–Whitney U (양측, 정규근사) + rank-biserial r = 2U₁/(n₁n₀) − 1 (양수 = TARGET=1 쪽 값이 큼). 분포 왜도 |skew| < 2인 변수에 한해 Welch t-test + Cohen's d를 참고로 병기 (금액형 heavy-tail 변수는 MWU만 사용).
- **범주형/구간형**: Pearson Chi-square 독립성 검정 + Cramér's V. 2x2 표에서 기대빈도 < 5이면 Fisher exact test.
- **구간별 관측 상환곤란율 (Observed Difficulty Rate)**: Wilson score 95% 신뢰구간.
- **다중 비교**: 아래 257개 검정 전체를 하나의 family로 보고 **Benjamini–Hochberg (FDR)** 보정 p-value(`p_adj (BH)`)를 사용한다. 보수적 기준인 **Bonferroni** 보정값도 함께 제시한다. Welch t-test는 MWU의 참고값이므로 family에 포함하지 않았다.
- 효과크기 라벨: |r|·V < 0.1 무시할 수준, < 0.3 작음, < 0.5 중간, 그 이상 큼 (Cohen's d는 0.2/0.5/0.8).
- ⚖️ 표시는 공정성 민감 속성으로 **기술통계 전용**이며 승인 기준으로 사용하지 않는다.

## 8. 해석 원칙

- 효과크기가 '무시할 수준'인 결과는 p-value와 무관하게 실무적 의미를 주장하지 않는다.
- 모든 결과는 연관(association)이며, 해당 Feature가 상환곤란을 유발한다는 인과 해석을 하지 않는다.
- 신뢰구간이 넓은 소표본 구간(n이 작은 범주)은 순위 비교에 사용하지 않는다.
- 공정성 민감 속성의 차이는 모니터링 목적의 기술통계이며 승인 기준이 아니다.
